# LAY BACK — филиал Третьяковская

HTML-макет главной страницы для передачи в вёрстку / Битрикс.

## Просмотр

- С компьютера: [GitHub Pages](https://a34203462-dev.github.io/layback/)
- С телефона: та же ссылка (мобильная версия включится сама)
- Принудительно: `?mobile=1` или `?desktop=1`

Локально: `node dev-server.js` и открыть `http://localhost:5173/`
